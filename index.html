Testing tips and limitations
  • Test in a quiet room. Start with the phone about 15–30 cm (6–12 in) from the clock.
  • Keep the phone still and avoid touching the case while measuring.
  • If it misses ticks, move the phone closer. If it detects room noise, move it farther away or reduce background noise.
  • Allow microphone access when Safari asks. Listening works only while this app is open in the foreground.
  • This is an early detector prototype. It reports detected sound intervals; it does not yet calculate daily gain/loss, bob movement, or which side to raise.
All audio processing stays on this iPhone. No audio is recorded, saved, or uploaded.
